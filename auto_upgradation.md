# IRCTC Auto-Upgradation Scheme

### How it Works:
- While booking a ticket, check the box labeled **"Consider for Auto-Upgradation"**.
- If upper classes (e.g., 2AC or 1AC) have vacant berths after charting while lower classes (e.g., 3AC or Sleeper) are waitlisted, IRCTC automatically upgrades passengers **at zero extra cost**.

---

### Key Rules:
- **No Extra Charges:** Upgradation is completely free.
- **Waitlist Cleared First:** Priority goes to confirmed passengers to upgrade them, which frees up lower seats for waitlisted passengers.
- **Entire PNR:** Either all passengers in a single PNR get upgraded together, or none do.
